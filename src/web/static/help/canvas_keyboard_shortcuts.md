### Interactive Canvas & Keyboard Shortcuts

Accelerate bounding box definition and ROI alignment with keyboard and mouse shortcuts:

| Action | Control / Key | Description |
|:---|:---|:---|
| **Draw Box** | `Click + Drag` | Click and drag on the interactive image canvas to create a new ROI box |
| **Select ROI** | `Click Box` | Click inside an existing bounding box to select it for editing |
| **Nudge Position** | `Arrow Keys` | Nudge selected bounding box by 1 pixel in any direction |
| **Fast Nudge** | `Shift + Arrow` | Nudge selected bounding box by 10 pixels for rapid repositioning |
| **Pan / Move** | `Hold Shift + Drag` | Pan the interactive canvas or move selected ROIs |
| **Batch Align Left** | Toolbar Button | Align selected ROIs to the leftmost X coordinate |
| **Batch Align Top** | Toolbar Button | Align selected ROIs to the topmost Y coordinate |
| **Equalize Size** | Toolbar Button | Standardize width and height across all selected digit boxes |
